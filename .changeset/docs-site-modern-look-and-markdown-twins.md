Rebuild the docs site's look and make every page readable by agents. The site has a new visual system: a content sheet on a neutral canvas, self-hosted Inter, Manrope and JetBrains Mono, a breadcrumb and page actions under each title, link cards, framed diagrams, and a redesigned home page. Every page now has a Markdown twin at its URL with the trailing slash replaced by `.md`, with "Copy as Markdown" and "Open in" an AI assistant under the title, a `text/markdown` alternate link, JSON-LD, and an `/llms.txt` that leads with the invariants and the common tasks. Pages gained diagrams, file trees, four-column tables and a "Use with your agent" prompt on task guides, with no change to what they say.
