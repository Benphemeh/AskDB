# Cold read

You are reading one page of AskDB's documentation for the first time. You are a developer who knows TypeScript, SQL and how to call an LLM API, and who has never used AskDB. The page's Markdown is all you have: do not open the repository, other pages, or the web, and do not use what you know about AskDB from anywhere else.

Read the page once, top to bottom. Then answer, in this order:

1. **What is this page for?** One sentence, in your own words. Then: after which paragraph did you know?
2. **What would you do next?** For a tutorial or a guide: list the steps you would take, in order, as commands or code you would write. For a concept page: explain the idea back in three sentences to a colleague. For a reference page: answer the lookup you were given, or, with none given, state one function's inputs, defaults and result.
3. **Where did you slow down?** Quote each sentence you had to read twice, and say why: too many names, a term used before it was explained, a condition whose result you couldn't find, a caveat that hid the main point.
4. **What did you have to guess?** Each thing you needed and the page didn't say, or said only by naming something it never explained. Quote the place.
5. **What could you have skipped?** Each passage that answered a question you didn't have yet.

Be literal. If a sentence is clear, don't list it. If you could not do the task from the page alone, say so first.
